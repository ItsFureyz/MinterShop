# MinterShopBot 1.2

## config.env
```
BOT_TOKEN=...
OWNER_IDS=123,456
ADMIN_IDS=123
RATE_RUB=1.34
RATE_USD=0.0149
RATE_EUR=0.0137
```

## Запуск
```bash
pip install -r requirements.txt
# заполни config.env
python bot.py
```

## Меню
- Веб-кошелёк (заглушка + баланс)
- Отзывы покупателей (пересланные сообщения)
- Купить чек → сделочный / дружеский
- Ваши чеки
- Кошелёк (баланс ⭐/₽/$/€, пополнить/вывести — заглушки)
- Магазин (заглушка)

## /settings (только OWNER_IDS)
- Отзывы: добавить (forward), список, смотреть №, удалить №
- Чёрный список + команда /appeal
- Сделочные чеки: список, удаление
- Премиум-пользователи бота (кто может создавать сделочные чеки)

## Сделочный чек
1. Нужен Telegram Premium + право в списке премиум-юзеров (овнер/админ — всегда)
2. Сумма звёзд + ссылка NFT
3. Сообщение с картинкой `media/deal_check.jpg` для пересылки продавцу
4. 🟢 Принять / 🔴 Отклонить

## Файлы данных
`data/*.json` — отзывы, ЧС, чеки, балансы.
